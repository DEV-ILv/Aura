# AURA -- Personal AI Assistant

> An open, modular, voice-controlled AI assistant built on ESP32
> hardware.

## Project Roadmap

  Version   Status
  --------- -------------------------
  AURA V1   ✅ Functional Prototype
  AURA V2   🚧 In Development

## AURA V1

### Hardware

-   ESP32-WROOM-32
-   SSD1306 OLED
-   INMP441 Microphone
-   MAX98357A Amplifier
-   4Ω Speaker
-   WS2812 RGB Ring
-   MicroSD Card
-   Touch Sensor
-   Wi-Fi

### Features

-   Voice Assistant
-   Speech-to-Text
-   Gemini AI Integration
-   Text-to-Speech
-   OLED UI
-   Reminder Manager
-   OTA Updates
-   Web Portal
-   SD Storage
-   FreeRTOS

### Status

-   Firmware architecture complete
-   Breadboard prototype
-   Functional proof of concept
